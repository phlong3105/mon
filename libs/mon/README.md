`🐈 mon` package for computer vision, built using [Python](https://www.python.org/) and [PyTorch](https://pytorch.org/). This package is designed to provide a comprehensive set of tools and functionalities for developing and deploying computer vision models.

<details>
  <summary></summary>
  Yes, you are right. It's named after my cat 🐈 (Mon).
</details>

## Package Structure

<details>
  <summary>Directory Structure</summary>

  ```text
  mon                     
  |__ shared                  # Common code shared across multiple projects is located.
  |   |__ mon                 # My main package
  |       |__ mon
  |       |   |__ core        # Base functionality for other packages.
  |       |   |__ datasets    # Dataset package.
  |       |   |__ vision      # Computer vision package.
  |       |   |__ ...      
  |       |__ pyproject.toml  # For both packaging and dependency management.    
  |       |__ README.md
  |__ ...
  ```
</details>
