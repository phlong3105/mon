# Useful Commands

---

## GitHub

- Add sub-module: `git submodule add <repository_url> <path>`
    ```commandline
    git submodule add 
    ```

- Remove sub-module: ` git submodule deinit -f <path/to/submodule>`
    ```commandline
    git submodule deinit -f 
    ```

## Poetry

- Install: `poetry install`
    ```commandline
    poetry install --extras "docs gui"
    ```
